# PiPod

A fork of Little Coder, that AI coding agent inference and execution in-browser.

- The LLM model is fetched from Hugging Face
- Inference runs in the browser with a combination of WebGPU and WebAssembly
- Execution runs in BrowserPod

## Using PiPod

- Type a request and press Enter
- `/` opens the command list
- `!` runs a bash command, for example `!ls`
- `esc` stops the current reply
- `ctrl-l` clears the screen, `ctrl-c` exits
- `ctrl-r` shows more shortcuts
