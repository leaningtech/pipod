PiPod

              
A free coding agent that runs entirely on your device, AI model included. Your prompts and code never leave it.

            

          

          
          

          

            

              Model
              
Larger models take longer to download and use more of your device. Smaller ones are quicker but less reliable at tool calls.

              

              

                Advanced
                
Legacy engine. These can be tried on devices with limited resources.

                

              

            

            

              Network access
              

                
                
              

              
Full internet access isn't available in this build.

            

            

              
Start downloads the model unless it is already saved in your browser. On weaker devices the browser may stop responding for a while.

              
            

          

        

        

          How PiPod works
          

            
Models

            
Open-weight models, licensed under Apache 2.0, downloaded from Hugging Face the first time you choose one. They're saved in your browser's storage, so later visits don't download them again.

          

          

            
Harness

            
A fork of Little Coder, which adapts the Pi agent harness for smaller models. PiPod's changes improve the harness and its compatibility with BrowserPod.

          

          

            
Inference

            
Models run on your device's GPU through WebGPU, using LiteRT-LM, whose runtime is compiled to WebAssembly. The legacy engine, Sipp, runs llama.cpp compiled to WebAssembly, also on WebGPU. Both are used unmodified. PiPod needs a browser with WebGPU.

          

          

            
Execution

            
Code runs in BrowserPod, a Linux-like sandbox with Node.js that runs in this tab. BrowserPod is used unmodified.
